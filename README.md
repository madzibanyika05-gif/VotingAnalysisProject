# VotingAnalysisProject
Development of the project for the main assessment.
This code is a voting analysis application that filters out the 2024 election results.

# Features
Some of the key features are calculating the percentage of male and female parties and getting details of a constituency.

# Requirments
Code runs on Python version 3.10. 
CSV is built in so no additional installations are needed ('EdidtedData.csv').

# Installation
To run code access will be granted to clone respiratory and download CSV.
https://olympus.ntu.ac.uk/N1192518/VotingAnalysisProject
Run with Python version mentioned
vap2.py

# Usage instruction
1. Launch the script and run to access main menu
2. Choose an option by entering a number from 1-7
3. Follow prompts for inputs like region name, constituency name etc...

# File structure
vap2.py contains the main program
EditedData.csv is the dataset with constituency details and voting details.
Make sure both are saved within the same file
